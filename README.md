## 📌 Projeto PROUNI (2005-2019)

**Objetivo:**  
Estudar a distribuição de bolsas do **PROUNI** entre 2005 e 2019, analisando perfil dos participantes e padrões de inclusão social.

**Ferramentas utilizadas:**  
- SQL Server.  
- Power BI. 

**Técnicas aplicadas:**  
- DAX.  
- Tratamento de dados. 
- Criação de funções, views e medidas.  
- Carregamento de dados em SGDB. 

**Principal base de dados:**  
- [Brasil Students Scholarship - Prouni (2005-2019)](https://www.kaggle.com/lfarhat/brasil-students-scholarship-prouni-20052019)

**Acesso ao dashboard:**  
- [Dashboard - PROUNI](https://bit.ly/4qMcImL)

**Conteúdo deste repositório:**  
- Arquivos SQL utilizados.  
- Bases secundárias utilizadas.
- Arquivo de texto com motivações, lições aprendidas e conclusões.
